# Публичный снимок памяти

`index.html` — страница, которую GitHub Pages отдаёт по адресу
`https://merumez.github.io/selective-memory-showcase/`.

Она **самодостаточна**: ни одного внешнего запроса, весь граф и все стили
внутри файла. Поэтому её можно открыть локально, отправить вложением или
положить куда угодно — она не перестанет работать.

## Разговор вымышлен, и это не формальность

В `storage/brains` лежат базы живых людей, разговаривавших с ботом.
Выложить снимок такой базы — значит опубликовать чужую переписку: адрес
рано или поздно утечёт, а восстановить по графу, кто и о чём говорил,
тривиально.

Поэтому страница строится из `demo_brain.db`, собранного
`tools/make_demo_brain.py` — это придуманный разговор, прогнанный через
настоящий движок. Никакой другой базы здесь быть не должно.

## Пересобрать

```bash
python tools/make_demo_brain.py -o docs/demo_brain.db
python tools/render_memory.py docs/demo_brain.db -o docs/index.html \
  --note "Демонстрационный снимок. Разговор вымышлен и прогнан через настоящий движок — ничьей личной переписки здесь нет."
```

Время в демонстрационном мозге зафиксировано, поэтому пересборка даёт тот
же снимок при том же разговоре.
