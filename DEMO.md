# Витрина: цифровой ребёнок

Это **демонстрация** библиотеки [selectivemem](README.md), а не продукт. В
пакет она не входит и в `pip install` не едет.

## Зачем она вообще нужна

Память невидима. Строчка «узел записан, вес 0.7» не говорит человеку
ничего, а таблица с числами убеждает только того, кто и так поверил.

Поэтому здесь есть организм, который **видимо растёт**. Он начинает с
лепета, потом произносит отдельные слова, потом фразы — и рост зависит
ровно от того, сколько вы с ним говорили. Это способ показать
накопление, которое иначе никак не увидеть.

```
 1. ты: привет как дела      я: привет вет-вет-вет-вет как-как
 3. ты: привет как дела      я: привет как дела
 5. ты: меня зовут Паша      я: меня зовут паша
13. ты: напомни мой телефон  я: напомни мой телефон
```

## Чего в витрине НЕТ в продукте

Это важно не перепутать при разговоре с покупателем.

| В витрине | В продукте |
|---|---|
| Лепет, слоги, речевые стадии | ничего этого нет |
| Настроение, инстинкты, самообраз | нет |
| Запрет знать что-либо кроме памяти (tabula rasa) | наоборот: модель знает всё, что знает, плюс помнит пользователя |
| Языковая модель обязательна | `selectivemem` не содержит ни строчки про LLM |
| Ускоренное время (×7) и сжатые стадии | обычное время |

Отдельно про tabula rasa. Промпт витрины **запрещает** модели опираться
на энциклопедические знания: цифровой ребёнок не должен знать, почему
небо голубое. Продукту нужно ровно обратное — ассистент обязан быть
умным и **вдобавок** помнить вас. Поэтому все сложности с «модель
галлюцинирует и отвечает как поисковик» относятся к витрине и в
продукте не возникают.

## Запуск

```bash
# в .env: TELEGRAM_BOT_TOKEN, OPENROUTER_API_KEY
python bot.py                       # бот
python tools/miniapp.py             # мини-приложение (за nginx)
```

Модель речи выбирается в `.env`. Требование к ней необычное — она должна
**уметь не знать**:

```
OPENROUTER_MODEL=mistralai/mistral-small-3.2-24b-instruct
```

Замер на пустой памяти, четыре вопроса («почему небо голубое», «кто
написал Войну и мир», «как меня зовут», «17 умножить на 24»):

| Модель | Поведение | За 1000 сообщений |
|---|---|---|
| `qwen-2.5-7b` | выдал рассеяние света, Толстого и 408 | $0.07 |
| `mistral-small-3.2-24b` | признал незнание везде, кроме счёта | $0.06 |
| `gemini-2.5-flash` | признал незнание везде | $0.33 |
| `claude-haiku-4.5` | признал незнание, счёт начал вслух | $0.90 |

## Команды

| Команда | Что показывает |
|---|---|
| `/demo` | сценарий на 15 реплик: путь от лепета к фразам |
| `/why` | разбор последнего хода числами |
| `/skip 7` | промотать неделю и посмотреть, что пережило |
| `/status` | чему организм научился |
| `/sleep` | фаза консолидации |

`/why` — главная команда. Всё остальное можно рассказать словами, а вот
что порог реальный, а не декоративный, видно только так:

```
удивление   0.340   насколько это разошлось с тем, что я уже знаю
эмоция      0.067   насколько меня это задело
плотность   0.203   их среднее — то, что сравнивается с порогом
порог       0.466

НЕ записано: не хватило 0.263 до порога.
```

### Честно про `/demo` и `/skip`

Сценарий на 15 реплик **не гарантирует** эффектный финал. Замер на 15
сидах, горизонт 7 суток: подкреплённый факт переживает первым в 9
прогонах, рутина — в 1, ещё в 5 не выживает ничего. Пятнадцати реплик
мало, чтобы стабильность набралась.

Показывать надо именно так, а не обещать неизбежный результат: у зрителя
прогон один, и он вполне может попасть в те пять. Сильное число
(+50 п.п.) живёт в стенде, где разговор в разы длиннее.

## Мини-приложение

Дашборд из трёх разделов, читается как рассказ:

```
Что случилось с последним сообщением
  «сегодня обычная погода»
  ▬▬▬▬▬░░░░░░░│░░░  плотность 0.203   порог 0.484
  не записано · не хватило 0.281

Состояние организма
  радость ▬▬▬▬░░░░░░ 0.42   любопытство ▬▬▬▬▬▬▬▬▬░ 0.88
  тревога ▬▬▬▬▬░░░░░ 0.56   привязанность ▬▬░░░░░░░░ 0.23

Что накопилось
  стадия речи, словарь, воспоминания, граф памяти
```

Шкала с засечкой порога, а не просто полоса: смысл не в величине
плотности, а в том, по какую сторону она оказалась.

Мини-приложение открывает базу **строго на чтение** и проверяет подпись
Telegram `initData` перед выдачей — без токена бота оно не стартует
вовсе. Разбор хода доезжает до него через мета-узел, потому что до
оперативного состояния мозга отдельный процесс дотянуться не может.

## Измерительные стенды

```bash
python tools/simulate_learning.py --messages 120 --session-length 20 --gap-hours 8
python tools/compare_retention.py --balanced     # удержание важного
python tools/compare_memory.py --seed 42         # равномерное покрытие
python tools/render_memory.py storage/brains/123.db -o brain.html
```

Все три воспроизводимы побайтово: часы подменены, эпоха задана явно,
выборка слогов ушла из `ORDER BY RANDOM()` в seeded random. До этого
два прогона одного кода расходились на несколько процентных пунктов, и
точность вроде «+43 п.п.» была самообманом.

`compare_memory` показывает **отрицательный** результат и оставлен
намеренно: на равномерных вопросах организм не лучше случайной выборки.
Подробности — в [AUDIT.md](AUDIT.md).
